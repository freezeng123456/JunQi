# 两类公开特征能否改善 BeliefNet：实验协议

本实验以冻结策略产生的同一批对局，比较现有 317 通道观测、公开长期轨迹、公开空间与攻防关系。它检验离线身份概率预测的可学习性、泛化和校准。参数 EMA 全程关闭，belief 训练使用独立监督损失，不把实验中的 belief 输出反馈进策略训练。

- 数据主体代码：`7a27b542744b084a7d1b13681ffc46bb9bcef3f5`；额外行为数据的索引修复：`b13fb2ead1e854a88d254bee19414e42f3f3af8b`。已完成的数据分片没有重新生成，失败记录保留。
- 两台服务器各独占一张 NVIDIA H20。Python 3.12，PyTorch 2.10.0+cu128，CUDA 12.8。代码 worktree 固定提交，输出与代码分离。
- A：`28.39.92.103`，长期轨迹与基线，配对种子 601、602、603。B：`28.39.92.105`，空间攻防关系与基线，同样的三组种子，另加 604 作为补充复核。
- 主训练在北京时间 2026-09-13 03:48 启动。A 硬截止 08:20，B 硬截止 09:20，分别比用户给出的释放时间提前 40 分钟。启动器只在启动时计算一次剩余额度，用一次性计时器停止训练；完成标记用于结果回收，不用于检查时间。
- 预期主单元数 A 为 6，B 为 8。每单元最多 50,000 次更新、训练及阶段验证时间最多 2,400 秒；触发时间限制的单元标为 partial，不能当作完整固定步数实验。

## 数据与信息边界

训练集有 1,024 个独立对局、30,868 个观察者局面、1,156,148 个有效身份标签。验证、主测试、偏好攻击的随机行为测试、均匀随机行为测试分别使用 128 个不同对局。同一对局的四个视角和所有时间点只属于一个分区；各分片的对局 ID 已核对互不重叠。

生成过程中先冻结模型可见输入，再读取模拟器真值作监督标签。只监督仍存活、属于敌方且尚未被公开规则确定身份的棋子。自己的棋子、队友棋子、空位和已确定身份不计入成绩。每个真实标签必须在公开规则允许的候选类型内。数据文件和来源策略均记录 SHA-256，训练前再次校验。策略只读取冻结 checkpoint 的原始 policy 参数。

长期轨迹的 32 个通道记录移动次数、停留时间、移动距离、方向变化、折返、访问过的位置，以及最近 4/16/64/256 步的移动摘要。输入接口只接受公开位置、存活状态和持续可追踪的棋子身份，不接受隐藏类型。轨迹记录扩展现有有限历史；方向分量使用世界坐标，同时给网络观察者座位信息。

空间与攻防关系的 32 个通道包括己方各类型棋子的邻近程度、假设身份下的攻防结果、到各阵营棋子的距离及局部密度。它们都是现有公开空间观测的确定性变换，检验的是表示方式是否帮助学习；几何距离不代表真实合法走法，也不增加新的隐藏信息。

数据分布有明显边界：主测试有效标签的开局/中局/后期数量为 94,776 / 50,994 / 80；约 16.1% 的待猜棋子有过公开移动。均匀随机行为测试含 20,664 个后期标签。不得把主测试总体平均数解释为充分验证了长局面的轨迹价值。

## 同一基线与训练

各组使用相同的 4 层 Transformer、8 个注意力头、256 维嵌入、2 层 64 通道 CNN、FFN 扩展系数 2、dropout 0.1。新增 32 通道经过零初始化的 1×1 适配层映射至 317 通道，再加到原观测上。基线保留相同适配层并输入全零新增特征；其适配层权重没有有效输入梯度。因此总参数数、核心网络及初始预测相同，但新增信息会让特征组的适配层成为有效参数。

每个种子的模型初始化、采样序列、批量 256、Adam 学习率 5e-5、梯度裁剪 0.5 均配对。BF16 前向，损失与概率计算用 FP32。启用严格确定性 CUDA 算法，两台机器的同种子基线预检指标完全一致。预检仅用了 4 个对局，训练与验证重用小样本，只证明执行链路可用，不作为泛化结果。

训练目标为公开规则候选集合内的身份负对数似然。无额外 belief PPO 项、无参数 EMA、无策略联训。每 500 步在独立验证集评分，以验证 NLL 最低的原始参数 checkpoint 作为最终模型，同时保存最后一步原始参数和优化器状态。主测试和两个额外行为测试只在每个单元优化结束后评估；分析不再据此调整本轮训练超参数。

## 分析口径

主要比较相同种子的“新增特征 − 基线”测试 NLL，负值为改善。并列报告 Brier 分数、分类准确率、ECE、错误且置信度≥90%的比例。按开局/中局/后期、棋子类型和是否公开移动作分解。对特征组另外做推理时置零和跨局面打乱新增特征的检验；这些干预可以检验模型对特征的依赖，不能单独证明因果机制或正常使用时的收益。

主比较使用配对种子 601–603，B 的 604 单独作为补充，不能给关系特征与轨迹特征使用不同的主样本数。检验 A/B 基线的初始化、数据、步数、最佳步骤及参数哈希是否一致。置信区间按训练种子和完整测试对局进行配对重采样，不把同一对局的大量标签当作独立样本；只有三组训练种子，因此区间和一致性只描述本轮证据。

另保留训练曲线末期与最优验证 checkpoint 的差异，区分训练拟合不足和对训练对局的过拟合。合法的隐藏身份交换反例已验证：两个不同的真实布局可以产生相同的现有观测和两类新增特征。这证明普遍完美识别不可能，但不提供本数据集的 Bayes 误差数值，也不能替代实际泛化测试。

本轮特征对照不验证接回在线联合训练后的稳定性、搜索收益或对局胜率；也不比较全局自回归联合隐藏布局模型。现有核心网络忽略显式 global 输入，两个特征方向也没有新增独立的全局身份计数通道。

## 主比较之外的探索性复核

首个种子的验证曲线已经显示训练损失下降而验证 NLL 上升，因此在主训练完成后安排一次数据量复核。此安排是在本轮进行中形成的探索性实验，不能称为预注册主比较，也不修改已运行主实验的协议。

A 生成 16 个新的训练分片，每片 256 个完整对局，种子基值为 `700100 + 2000*i`，共新增 4,096 个独立对局。两台机器共同使用原有 1,024 个训练对局加这批新数据，共 5,120 个训练对局。原验证、主测试及两类额外行为测试保持同一份文件。扩充数据生成与训练代码固定为 `d958f70b9822a711354f1eb047fdb02f09a26f04`。

两个方向各做与基线配对的 601、602、603 三个种子，网络、特征、学习率、批量、损失及 dropout 与主实验一致。每单元固定 5,000 步、每 500 步验证、最多 400 秒；时间不足标为 partial。它与原主实验的 50,000 步上限不同，比较数据量效应时必须检查原模型的最优验证 checkpoint 是否位于前 5,000 步，保留训练曝光和选择窗口的边界。

分组中的“移动过”合并原观测的空走计数与成功吃子计数；成功吃子也会改变位置。合并后的公开计数已在全部 8 个原始数据分片上与独立轨迹记录逐标签核对一致。

另外加入三个只用训练标签拟合的简单表格参考：初始时刻的“原始位置 → 类型频率”、全时段的同一位置频率，以及“原始位置 + 公开移动次数分桶 → 类型频率”。全部采用固定加一平滑和公开候选类型遮罩，没有在测试标签上拟合。它们用于判断网络的改善是否只是在学习布阵先验，属于事后解释性对照。

各服务器的所有训练结束后，再对保存的最优模型评估公开移动分组，并分别评估最优参数和最后一步原始参数在完整训练数据上的表现。该诊断代码固定为 `0c10407d1c58e3cd5888facb46b49e093c5c1a93`。数据扩充、补充训练和诊断均受原 08:20／09:20 硬截止约束，不占用 40 分钟回收余量；额外阶段是否完成由独立退出状态与文件标记决定。

主实验前几个单元的最优模型均落在首次非零验证步骤 500，因此最后增加一项早期验证分辨率检查。在各服务器的主训练、扩充复核和保存模型诊断全部成功结束之后，使用原训练代码 `57940a09dd3ad0b24534a827e0c7b3ffda252ffd`、原 1,024 个训练对局和 601–603 三个配对种子，从相同初始化重跑 1,000 步，每 50 步验证，每单元最多 100 秒。两个方向仍各有相同的三个基线；全部受原硬截止约束，不能占用释放前 40 分钟余量。

该项属于进行中追加的探索性检查，只改变观察与选择早期 checkpoint 的分辨率。分析核对第 500、1,000 步的全部验证指标与对应主实验完全一致，并把每十个 50 步窗口的训练损失合并，与原 500 步窗口核对。若选择了同一步，额外核对实际最优权重相同。它不提供新的独立对局或训练种子；原主实验、扩充复核和重评分仍单独保留。该项是否完整完成单独列示。

## 对随机对手的独立策略复测

用户在本轮进行中明确优先尽快达到对随机对手的全胜，同时继续完成特征工作。因此追加固定策略复测，独立于上述 BeliefNet 特征因果比较。A 使用 frozen_policy_v4.pt（guarded_s501 原始策略），B 使用 ckpt_001000.pt 的原始策略。B 原元信息为观测语义 v3；复测明确只在内存中将校验元信息迁移至 v4，逐项校验其余架构，使用当前 v4 输入而不更新或改写权重，不声称复现旧运行。两条路径均不加载学习型 BeliefNet 或 EMA。

CPU/FP32 各测 512 局，共 256 个换边布阵对，初始布阵种子 3,001,100、对手随机种子 4,001,100。按 32 个块逐块保存每个完整的 16 局。每个进程最多两个 CPU 线程，GPU 显式不可见，单次评估上限 3,600 秒。

为优先验收棋力，GPU 复测排在同机主实验、扩充复核和保存模型诊断之后、早期选模分辨率补充项之前。A 先验证原始 ckpt_001000，B 验证 frozen_policy_v4；这与 CPU 的主机分配相反，汇总按实际检查点身份匹配。BF16 各测 2,048 局，共 1,024 个换边布阵对，初始布阵种子 3,021,100、对手随机种子 4,021,100。每 128 局保存一次；同一 GPU 没有其他计算进程时才启动，并继续受原 08:20／09:20 截止约束。调整发生在对应排队父进程尚未启动任何 GPU 子进程、尚无结果目录时，原始方案和日志保留。

全部为 DARK、四席独立均匀随机布阵、贪心策略、均匀随机合法动作对手、每局 4,000 步上限。同一后端内两份策略的布阵和对手种子相同，逐局对比布阵 SHA-256。CPU 与 GPU 的随机动作流并不相同，也不使用同一批测试种子。统计必须报告胜负和及未完成局数；若估计两份策略差值，按完整布阵对重采样，保留两种执队结果的关联。

阶段 A 无 Belief 的微调配置和 v4 原始策略初始化已准备并本地重载验证，尚未启动候选训练。是否追加训练由复测失败证据决定；初始化文件不计作新训练结果。相关准备、原始输入哈希和结果逐局记录加入交付包。

## 原始策略大样本反例后的条件式后续

A 的当前规则 GPU 验收完整得到 2,045 胜、1 负、2 和／2,048 局；CPU 新 512 局全胜记录仍独立保留。A 按原 08:20 硬截止结束，未追加策略训练。

B 在主实验、扩充复核、保存模型诊断及 guarded 策略的 2,048 局复测之后作一次条件决策。若 guarded 已全胜，则继续原可选早期选模检查，不追加策略训练。若仍有非胜局且原 09:20 硬截止内的剩余预算足够，则以策略微调替代 B 的可选早期检查。该替换只停止了尚未产生子进程或输出目录的原 B 排队父进程，未修改任何特征训练或诊断。

微调使用已验证的 v4 原始策略初始化、空优化器和从零开始的 rollout 计数，不接入 BeliefNet、布阵训练或 EMA。学习率固定 1e-5，128 个环境，每轮 512 步；在 64、32 轮中选取能够覆盖保守估计“每轮 7 秒＋加载、两份完整验收和收尾合计 360 秒”的最大轮数。预算不足则不启动策略训练。以事先确定轮数的最终检查点验收，不根据新验收局挑选中间检查点。两份策略各测新的 2,048 局（1,024 个换边布阵），布阵种子 3,031,100、随机种子 4,031,100；训练内监控种子仍为 3,011,100／4,011,100。

此时后续仅为条件式排队，实际是否训练、轮数、退出状态和胜率必须以 phase_a_decision_B.json、phase_a_followup_status.json 以及 analysis_policy/phase_a.json（若产生）为准。原来的全部非胜记录继续保留；新的有限验收全胜不证明任意局面必胜。
