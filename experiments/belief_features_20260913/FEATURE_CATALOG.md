# 两类公开特征的实际定义

本表对应已经冻结并运行的 `features.py`，通道下标从 0 开始。它说明本轮实际测试的内容，不把未运行的后续改进混入当前结果。

共同接口输出 32×17×17 的额外特征，通过零初始化的 1×1 卷积映射到原有 317 通道，再输入相同的 BeliefNet。零特征基线保留相同参数结构。两个方向都不能读取模拟器隐藏棋型；真实身份只作为训练监督标签。

## 长期轨迹：以棋子为单位的公开历史摘要

跟踪器读取公开位置、存活状态和可持续追踪的棋子标识。棋子在一次更新前后都存活且位置改变时才记为移动，包含成功吃子后的位移；失败进攻死亡不产生伪移动，存活防守方也不会迁移到攻击起点。整批对局结束后重置状态，同一批内不以新对局替换结束对局。

下表中，t 是从开局开始的全局行动步数，m 为累计移动次数，D 为累计的移动端点曼哈顿距离，d 为一次端点位移。`clip01` 表示截断到 [0,1]。这些距离没有重建沿铁路拐弯的完整路径，因此不能解释为真实行走路径长度。

| 通道 | 程序名称 | 实际定义 |
|---:|---|---|
| 0 | log_moves | log(1+m) / log(1025) |
| 1 | idle_age | clip01((t−最后移动步骤)/256)，从未移动时最后移动步骤为 0 |
| 2 | ever_moved | 是否曾移动 |
| 3 | start_displacement | 当前格到初始格的曼哈顿距离 / 32 |
| 4 | distance_total | clip01(D/256) |
| 5 | distance_mean | D / max(m,1) / 16 |
| 6 | distance_max | 最大单次端点曼哈顿距离 / 16 |
| 7 | long_moves | clip01(端点曼哈顿距离大于 1 的移动次数 / 128) |
| 8 | direction_changes | clip01(连续两次非零位移向量叉积不为零的次数 / 128)；不包括严格 180° 反向 |
| 9 | reversals | clip01(连续两次位移向量点积小于零的次数 / 128)；包括钝角转向，不仅是原路退回 |
| 10 | unique_cells | 已访问过的不同格子数 / 129，包含初始格 |
| 11 | first_move_age | 首次移动发生的全局步骤 / 1024；从未移动时为 0。名称中的 age 实际表示发生步骤 |
| 12 | has_first_move | 是否发生过首次移动；本版本与通道 2 完全重复 |
| 13 | time_since_first_move | 曾移动时为 (t−首次移动步骤)/1024，否则为 0 |
| 14 | net_dx | 当前相对初始位置的世界坐标 x 位移 / 16 |
| 15 | net_dy | 当前相对初始位置的世界坐标 y 位移 / 16 |
| 16 | last_dx | 最近一次移动的世界坐标 x 位移 / 16 |
| 17 | last_dy | 最近一次移动的世界坐标 y 位移 / 16 |
| 18 | horizontal_moves | clip01(x 端点坐标发生变化的次数 / 128) |
| 19 | vertical_moves | clip01(y 端点坐标发生变化的次数 / 128)；与通道 18 不互斥 |
| 20 | right_angle_turns | clip01(连续两次非零位移向量点积为零的次数 / 128) |
| 21 | revisits | clip01(再次到达以前访问格子的次数 / 128) |
| 22 | move_rate | m / max(t,1) |
| 23 | travel_rate | D / max(t,1) / 16 |
| 24 | moves_last_4 | clip01(最近 4 个全局行动步内的移动次数 / 1) |
| 25 | moves_last_16 | clip01(最近 16 步内的移动次数 / 4) |
| 26 | moves_last_64 | clip01(最近 64 步内的移动次数 / 16) |
| 27 | moves_last_256 | clip01(最近 256 步内的移动次数 / 64) |
| 28 | long_last_4 | clip01(最近 4 步内的长移动次数 / 1) |
| 29 | long_last_16 | clip01(最近 16 步内的长移动次数 / 4) |
| 30 | long_last_64 | clip01(最近 64 步内的长移动次数 / 16) |
| 31 | long_last_256 | clip01(最近 256 步内的长移动次数 / 64) |

所有棋子特征乘以存活掩码，写到各自当前格上，再按观察者旋转整张特征图。向量分量的数值仍按世界坐标表达，没有跟随图像旋转分量；网络另有观察者席位输入。通道数为 32，但不代表 32 个相互独立的统计量；尤其通道 2 与 12 的重复在本轮保留并披露。

现有观测已经提供最近 32 步的起点/终点平面和累计战斗等统计。本轮只增加上述更长时间尺度的摘要，没有运行完整历史序列模型，也没有使用 EMA。部分归一化项没有截断，不能假设所有通道数值均处于 [0,1]。

## 空间与攻防关系：当前公开观测的变换

本方向只读取观察者现有的公开观测，不能读取敌方真实类型或敌方合法动作列表。使用曼哈顿半径 2 的核：距离 1 权重为 1，距离 2 权重为 0.5，其余（包括中心）为 0。棋型顺序固定为：军旗、地雷、炸弹、司令、军长、师长、旅长、团长、营长、连长、排长、工兵。

| 通道 | 内容 | 实际定义 |
|---:|---|---|
| 0–11 | 己方十二种已知棋型的几何近邻量 | 对对应己方棋型占位平面卷积，除以 5，再截断到 [0,1] |
| 12–23 | 假设该格棋子分别为十二种类型时的攻防分数 | 将邻近己方棋型量与规则战斗结果表相乘，除以 max(邻近总量,1)；假设攻击方吃掉己方棋子记 +1，被己方棋子吃掉记 −1，其他为 0；不能移动的假设攻击类型整行为 0 |
| 24 | 最近己方棋子 | exp(−最近曼哈顿距离/4) |
| 25 | 最近队友棋子 | exp(−最近曼哈顿距离/4)，包含暗置队友的公开占位，不需要队友真实棋型 |
| 26 | 最近左侧敌方棋子 | exp(−最近曼哈顿距离/4) |
| 27 | 最近右侧敌方棋子 | exp(−最近曼哈顿距离/4) |
| 28 | 己方局部占位密度 | 对该阵营占位平面卷积，除以 5，再截断到 [0,1] |
| 29 | 队友局部占位密度 | 同上 |
| 30 | 左侧敌方局部占位密度 | 同上 |
| 31 | 右侧敌方局部占位密度 | 同上 |

这些分数是工程特征，不是攻击成功概率或合法威胁图。几何相邻不保证道路/铁路连通、营地可攻击或中间路径无阻挡；一次假设战斗的规则结果也不代表该攻击现在合法。关系方向是对原有公开输入的确定性变换，其可能价值来自表示方式，不能声称新增了隐藏信息。

## 冻结结果与后续版本的边界

本轮训练值、参数数量、通道顺序、归一化和数据快照保持冻结。重复标志、世界坐标分量以及端点距离的定义均不在运行中悄悄修改。后续若去掉重复项、统一方向表达或增加完整路径/历史序列，应单独建立特征版本，并重新做相同基线的保留对局对照。
