# 事实基线与联合 BeliefNet 对局比较

## 冻结的实验定义

| 项目 | A：事实基线 | B：事实联合信念与搜索 |
| --- | --- | --- |
| 策略权重 | facts-counted-g10017 π₀ | 完全相同的冻结 π₀ |
| 策略输入 | 317 空间通道，0 全局维度，known_only，语义 v5 | 相同 |
| 信念模型 | 无 | 新训练的自回归联合 BeliefNet |
| 隐藏身份 | 未知身份通道置零 | 神经网络依次预测其余三方全部 75 枚初始棋子，包含阵亡棋子 |
| 行动选择 | 从策略分布采样 | 对全部合法根动作搜索，按 `log π₀ + Q / β` 更新后采样 |

父策略 SHA-256：`ef60cd5f21086e77a61a4744b57b267d51590fae3df1d659fc87b09458661aa1`。
计数训练阶段完成 10,017 局；更早的 512 指 rollout 数，不能当作完整对局数。
本轮不更新 π₀。比较衡量增加信念与搜索后的系统效果，不将全部差异归因于 BeliefNet 本身。

## 输入与约束

神经网络编码 129 个棋盘位置、最近 64 条公共事件和各棋子的可见事实。
完整公共历史另外用于硬约束：已知身份、合法类型域、初始库存、战斗关系，以及无合法行动导致的灭国事实。
约束只回答某个身份是否可行，不分配概率；可行身份之间的权重由神经网络学习。

阵亡棋子的身份仍在联合序列内。重建世界只读取观察者的已知初始身份、生成身份和公共历史；
不得复制真实对手棋子或真实世界的私有战斗记忆。
每次决策重新生成样本，完整重放公共历史，并核对观察者的 317 通道和合法动作集合。
有限预算内未获得合格样本时明确报错，不回退策略。

64 条事件是神经网络的历史窗口，不能宣称模型读取了所有历史行为信息。
完整历史硬约束和重放补充的是合法性，不能代替对更早行为的统计建模。

## 数据和训练

- 冻结 π₀ 生成 2,000 局完整自对弈，按波次批量执行；不重置尚未结束的局。
- 每局从时间分层中抽取 8 个位置，轮换观察者。整局不足 8 步时不会复制样本。
- 每局逐手 CPU 回放，核验 GPU 席位、战斗结果、终止状态及胜负。
- 按初始布局 SHA 划分约 80%/10%/10% 的训练、验证和测试集。同局所有观察者归于同一集合。
- 真实身份仅作为监督目标保存，不能进入输入构造。教师强制掩码只依赖当前事实和之前的身份标签。
- 精确约束掩码在 CPU 并行预计算并保存。训练不逐 minibatch 重解约束。
- 默认训练 10 epochs、batch 32、Adam、学习率 `1e-4`；64 维嵌入、两层编码器、两层解码器。
- 损失排除直接已知或逻辑唯一的身份，只用验证 NLL 选择权重。模型选择之后才打开测试集。
- checkpoint 绑定输入结构、约束版本、父策略、完整数据清单和训练配置；保存 optimizer 和 RNG 以恢复训练。

NLL 和 accuracy 都是 **teacher-forced conditional** 指标，不是边缘概率准确率，也不代表棋力。
训练数据局数为主要规模指标，epochs、更新次数和 GPU 时间是补充。

## 工程验收

1. 原生 CUDA 构建及事实输入、局数计量、无全局输入测试。
2. 实际冻结 π₀ 的 CPU/V100 输入和输出对比，短 PPO 保存/恢复与连续运行精确对比。
3. BeliefNet CUDA 前向对比、反向梯度、严格合法采样；同模式比较 BatchNorm。
4. 独立 40 局、每局 2 个位置、64 步上限的数据采集与续跑检查。这些短局只用于验收。
5. 同一验收数据上比较连续 2 epochs 和 1 epoch 后恢复到 2 epochs，逐 tensor 核对模型、optimizer、best weights 和 RNG。
6. 完整对局机制检查后，固定搜索预算，再进入正式对战。

正式训练和评测必须在这些验收通过后执行。单纯源码实现、本地测试或提交 Slurm 不算 GPU 验收完成。

## 配对对局

全新布局使用独立种子，并逐一排除真实训练数据清单内的所有布局，包括验证/测试布局。
同一布局进行两局，交换 B 的队伍；B 控制该队两名玩家，A 控制另一队。
双方采用同一游戏终止规则，超时或未完成的局不计为和局。
首版搜索默认每决策 1 个联合样本、1 步搜索、`β=0.5`，全部合法根动作使用相同样本与深度。
最多进行 8 批神经提案；正常首次通过时只执行 1 批，耗尽预算仍失败退出。
这属于有限计算预算的首版比较。

结果分别报告胜/负/和、原始胜率 `胜/总局数`、得分率 `(胜+0.5×和)/总局数`。
只用完整换队配对计算正式统计，置信区间以整对布局为 bootstrap 单位。
并行 worker 必须共用同一个目录级协议；每局保存协议哈希、布局哈希、种子、终止原因、搜索覆盖率和拒绝计数。

## 当前命令

在已分配的计算节点中运行：

```bash
python scripts/collect_facts_belief_data.py --checkpoint PI0 --output DATA \
  --games 2000 --positions-per-game 8 --num-envs 64 --workers 4
python scripts/train_facts_joint_belief.py --policy PI0 --dataset DATA --output TRAIN
python scripts/evaluate_facts_joint_belief.py --policy PI0 --dataset DATA \
  --joint TRAIN/joint-belief.pt --output TRAIN/test-audit.json
python scripts/compare_facts_joint.py --policy PI0 --joint TRAIN/joint-belief.pt \
  --dataset DATA --output MATCHES --pairs 100
python scripts/aggregate_facts_comparison.py --output MATCHES --require-complete
```

旧概率输入原型仅保留显式 `legacy_*` 入口用于历史结果复现；不进入上述执行链路。
新旧网络共用的因果注意力数学实现已提取至 `networks/causal_decoder.py`。
