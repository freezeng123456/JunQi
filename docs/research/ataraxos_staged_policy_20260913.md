# 先稳定行棋策略，再引入 BeliefNet

核查日期：2026-09-13。当前目标优先级是尽快在严格的对随机对手测试中取得全胜，同时完成已经启动的公开特征实验。本文中的候选配置不代表已经执行的新训练。

## 原作依据与本地取舍

Ataraxos 先训练最终行棋和布阵策略，再用它们生成对局来训练 belief；belief 为测试时搜索提供隐藏配置样本。它没有用这一实验顺序证明持续变化的 belief 输入与 PPO 在线联训一定更好。[论文 §2.5、附录 D.5](https://arxiv.org/html/2511.07312v1#S2.SS5)

因此，本项目采用分阶段路线是有原作依据的。我们保留公开规则推理、战斗历史和攻防特征，先把原始行棋策略对均匀随机对手的结果做稳；特征可学习性仍作为独立的监督学习问题完成。等特征在保留对局上显示价值，再决定是否接入行棋策略。离线身份预测改善不能直接当作棋力改善。

无 EMA 是用户明确要求的本地选择。Ataraxos 原作与官方实现使用 EMA，因此这里只借鉴其阶段安排，不能把本方案称为完整复现。[官方 belief 训练器](https://github.com/AtaraxosAI/stratego/blob/92db29e8ffc323b1b8a2804b5c3f84695d036b05/pyengine/belief/belief.py#L24)

## 已有棋力证据的边界

旧的观测语义 v3 训练共完成 1,000 个 rollout，保存原始 `ckpt_001000.pt`。独立 512 局测试由初始的 309 胜、174 负、29 和变为最终 512 胜、0 负、0 和，两种执队方式各 256 胜。相同检查点最后一次训练监控测试为 127/128 胜。这两个不同测试集的结果都保留，不能仅挑全胜的一个。

旧检查点记录了 2,000 次 belief 更新，但 1,000 轮日志中有 539 轮报告交叉熵为零、243 轮报告敌棋监督密度为零。因此，不能以更新计数或旧全胜记录证明 BeliefNet 有效。旧结果也不能直接作为当前观测语义 v4 的验收。

当前复测比较两份固定权重：特征数据所用的 `guarded_s501` v4 原始策略，以及旧 `ckpt_001000` 的原始策略。后者明确作为“权重不变、输入改用 v4”的迁移复测，保留源文件、原始元信息和 SHA-256；没有改写旧实验。

CPU 复测每份 512 局，使用新布阵、双方换边、FP32 和贪心动作。后续 GPU 复测每份 2,048 局，使用另一批新布阵和 BF16。两份策略在各自后端内使用相同的布阵与随机种子；CPU 和 GPU 的随机对手实现使用不同随机数流，不能声称跨后端逐步动作相同。两条评估路径都不接入学习型 BeliefNet，也不使用 EMA。完整结果以 `analysis_policy/current_cpu.json` 和 `analysis_policy/current_gpu.json` 为准。

CPU 复测已完整回收并通过文件清单、逐局计数与配对布阵哈希校验：原始策略 512 胜、0 负、0 和，两种执队各 256 胜；guarded_s501 为 511 胜、1 负、0 和，其中队 0 为 255 胜 1 负、队 1 为 256 胜。两份固定检查点间只有一局结果差异，不能据此断言普遍存在显著棋力差异。GPU 的另一批 2,048 局验证仍需单独完成。

“1.00”在验收中必须同时给出胜、负、和及总局数；四舍五入显示为 1.00 不算全胜。有限测试集的全部胜利也不等于任意新局面的真实胜率严格为 100%。

## 阶段 A 的可执行准备

`configs/phase_a_random_no_belief_20260913.yaml` 已通过配置校验。它关闭布阵训练与 BeliefNet，使用当前公开规则输入和原始策略参数，保留 PPO 裁剪与 KL 约束。候选预算为 128 个 rollout；每 16 轮用独立的 256 局验证集检查，最终另测保留集。固定学习率 1e-5、探索系数 0.002 是短程稳态微调候选，尚未证明最优。

`prepare_phase_a.py` 已从原始策略生成单独的 v4 初始化文件：策略各张量与源文件精确相等，优化器状态为空，梯度和 rollout 计数均为零，重新载入成功。该步骤没有执行参数更新，也没有覆盖旧检查点。实际追加训练应由当前复测中的失败证据触发；若现有原始策略通过全胜验收，应先保留结果，避免继续训练造成回退。

## 特征实验继续完成的内容

长期轨迹和空间攻防关系各增加 32 个公开通道，使用相同的零初始化适配层和相同的 BeliefNet 骨干，与对应零通道基线做配对比较。原有观测已经包含短期行动平面与累计战斗统计，长期轨迹提供的是更长时间尺度的汇总，不能称作首次引入全部历史或完整历史序列模型。

本轮先冻结策略生成数据，对比主数据量、五倍独立训练对局、已保存模型重新评分和更密的早期验证间隔。主实验、追加探索和重复评分分开报告。它们不占用策略梯度，也不会在特征尚未验收时自动改变行棋网络的输入。

两个已授权 H20 租期继续使用原定停止期限与回收缓冲。后续 GPU 检查只在同一台机器的既有特征队列完成后启动，每张 GPU 同时只运行一个训练或评估进程；采用一次性截止定时器，不创建检查时间的监控任务。
