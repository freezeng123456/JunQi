# BeliefNet 与策略的联合学习及坍缩约束

> 历史试验记录：下述四格运行使用 EMA，结果与原协议保持不变。后续代码已按用户要求移除参数 EMA；当前设计与核查见 [无 EMA 的 Ataraxos 借鉴记录](ataraxos_no_ema_20260912.md)。本页结果不能归属于新的无 EMA 版本。

本轮采用交替协同训练：同一批自我对局同时提供策略回报和 Belief 身份监督；两个网络使用独立参数、优化器与梯度。先完成当前 rollout 的 PPO 更新，再更新 BeliefNet，并把有限权重的 EMA 预测交给下一轮采样。尚无长期不坍缩的保证；本轮目标是验证有效学习、信息边界与局部稳定性。

## 已核实的起点

旧运行配置已经开启 BeliefNet。问题首先在数据：`RevealTracker` 只在终局为最后行动者标注仍存活的敌棋，获胜方可能没有任何有效标签。原损失把标签数下限截为 1，空样本便表现为 CE=0、优于均匀基线，但仍执行 Adam 和 EMA 更新。

Ataraxos 附录 D.5 描述的是用最终布阵/行动网络生成的自我对局位置训练 Belief；“final networks”不表示仅用终局盘面。其原文也不能作为无约束端到端联合微分稳定性的证明。[原论文 D.5](https://arxiv.org/html/2511.07312v1#A4.SS5)

## 一轮训练的数据流

1. 从自我对局中每 16 步抽取两个环境的四方观察。先冻结玩家输入，再读取当前隐藏棋型作为独立的监督标签。排除本方、队友、空格及已经确定的身份，避免用显然已知的标签抬高准确率。
2. BeliefNet 只读取玩家观察；输入中的概率通道还原为独立的规则分布，避免把上一次网络猜测循环当作新证据。真值只用于监督损失，不能进入推理输入。
3. 策略用采样时保存的 317/28 观测完成 PPO 更新。当前 rollout 不重新计算 Belief 输入，不改变已经采集数据的条件分布。PPO 本身交替进行采样与固定数据上的优化；这里对 Belief 输入加以固定，是对其适用边界的工程约束。[PPO 原论文](https://arxiv.org/abs/1707.06347)
4. BeliefNet 用独立监督交叉熵训练，数值有限且有有效标签才执行优化器和 EMA 更新。空标签、非有限损失、非有限梯度分别计数，不作为有效学习步。
5. 从第 8 轮后逐渐将 EMA 预测加入规则分布，16 轮升到最多 25%。新输入仅在下一轮生效。布阵网络在此次试验中保持关闭，减少同时移动的训练目标。

## 能约束什么，不能保证什么

设规则分布为 r，将神经预测限制在规则允许的类型内并归一化，得到 q。注入分布为

`b = (1 - beta) * r + beta * q, 0 <= beta <= 0.25`。

因此每次注入时，对每个规则允许的类型有 `b(type) >= 0.75 * r(type)`。规则排除的类型仍为 0；公开身份仍是 one-hot。这能防止一次不可靠预测把所有其他候选概率压到 0。后续真实公开事件可以合理地收紧分布，这条下界不应被误解为整个对局中固定不变的熵下界。

利用 KL 的凸性，`KL(b || r) <= beta * KL(q || r)`。程序进一步降低每个棋子的 beta，使每次注入相对规则分布的 KL 不超过 0.05。若输入变化让固定策略在当前四方局面的最大动作 KL 超过 0.02，或平均动作熵低于注入前的 95%，则逐次减半权重；仍不满足就恢复注入前的实际分布。

上述数值是本轮明确冻结的保守工程阈值，不是普适最优参数，也不是对全局学习轨迹的收敛证明。Belief 变准后熵降低可以是正常现象，判断坍缩必须同时看留出局面 NLL/Brier、错误高置信率、策略条件熵、数值状态和对局表现。不能靠强制每个棋子的分布都宽来定义稳定。

## 配对短试验

- 初始策略：此前 `ckpt_001000.pt`，SHA-256 `4e75bb094122b119ba15caf94632fcd4e173dbb77ce08d4e6ab9c6bd7716756a`。作为观测版本 4 新实验的权重初始化，显式允许从版本 3 迁移；优化器、计数器和 BeliefNet 重建，原训练不被续写。
- 两个种子：501、502，顺序 shadow/guarded、guarded/shadow。每格 32 个环境 × 128 步 × 48 轮，共 196,608 环境步。
- shadow：同样采样并训练 BeliefNet，权重 beta=0，不影响策略。guarded：使用上述逐步接入及回退约束。两组初始策略、BeliefNet 初始化、学习率、布阵分布和采样方法相同。
- 固定探针：独立布阵种子 910000–910007，开局及第 16/64/128 步；实际保存 31 个盘面、124 个玩家视角、4,050 个未确定敌棋标签。它用于诊断，不参与梯度；早停使用它，因此最终指标不能当作未触碰的最终验收集。
- 立即停止非有限更新；固定探针归一化策略熵低于初值一半时停止；神经 NLL 连续三次比初值恶化超过 0.25 时停止。总试验墙钟预算最多 900 秒，外层还保留硬超时和原租期边界。

短试验通过只支持“该配置下完成了这段联合学习且未触发预设坍缩信号”。它不证明棋力提高，不替代长期多种子、自博弈对手池、不同布阵和新保留测试集的验证。后续是否加大 Belief 权重或接入 PPO 梯度，应依据这些证据决定。

最终运行代码的本地全量回归为 1,374 passed / 171 skipped / 4 warnings，H20 定向回归为 62 passed。四份 checkpoint 每份检查 595 个张量均有限；在本地 CPU 用已保存权重复算所有最终探针指标，最大差异 8.11e-6。同一 GPU/PyTorch 环境复建初始网络，初始探针误差为 0，Belief 的 47/47 个可训练参数张量均有变化，最大绝对变化在 0.01042–0.01152。

第一次尝试因全局 minibatch 分组中的三个不适用统计字段被记录为 NaN 而停止。新增真实 PPO 回归先复现，再修正字段输出并按原协议重跑；原失败证据保留。运行后的审计另发现 `belief_max_parameter_change=192` 包含 BatchNorm 的计数器，不能当作权重变化量。此后仅修正了报告函数并增加专项测试；原始运行记录保持不变，上述权重变化来自同环境重新核验。训练算法、阈值及结果没有因此重跑或改写。

本轮建议保留监督梯度隔离、规则混合上限和发布检查。下一阶段应在扩大时长之前加入独立最终测试集和对局棋力评估，重点跟踪 seed 502 所示的策略集中趋势；暂不据此增大耦合权重。
