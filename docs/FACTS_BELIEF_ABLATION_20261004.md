# 事实信念对照实验：2026-10-04

## 问题与冻结边界

上一轮完成直接策略与联合信念加搜索的 200 局比较，联合版本胜率 53%，配对区间 47%–59%。本轮补齐神经边缘信念对照，检查学习条件关联是否产生额外收益。所有组继续使用冻结的 `facts-counted-g10017`，不更新走子策略，不引入旧规则概率。

三组分别为：A，π₀ 直接走子；M，π₀ + 边缘信念 + 搜索；J，π₀ + 自回归联合信念 + 搜索。以名称而非旧文档的 B/C 编号识别组别。

- 两个信念训练种子：20261004、20261005。每种模型每个种子 10 epochs，batch 32，Adam 学习率 1e-4。编码器、历史窗口、维度与层数相同；记录实际参数差异。
- 各模型仅根据自己的验证 NLL 选择 epoch。边缘 CE 不使用真实身份前缀；联合模型 teacher forcing 的真实前缀只进入因果解码支路。
- 边缘输出是事实条件下的逐棋子神经分数，经同一逐前缀可行性约束顺序采样；不能将其称为全局条件化乘积分布的精确采样。联合模型同时学习前缀条件关联。
- 两种模型 NLL 定义不同，不直接以数值大小判定优劣；自由采样和实际对战分别报告。

## 正确性与效率

新增边缘模型需要通过隐藏标签不变性、严格 checkpoint、CPU 检查以及实际 V100 保存恢复/可行采样/全动作搜索验收。

约束优化仅缓存不可变位集合和相同军队类型域的匹配结果。保持约束语义 q12.v2、搜索节点预算和可行样本不变，使用冻结旧实现进行逐结果对照，另测冷局面耗时。两组使用同一优化后的求解器。

开发诊断使用原 validation 信息状态，分别测 1、2 个样本的可行性、重复率及推理耗时。第一轮正式机制对照固定为 **1 样本、深度 1、β=0.5、全部合法根动作、最多 8 批提案**，与前轮预算一致。2 样本诊断用于下一轮预算选择，不根据本轮正式胜率修改参数。

## 正式对局

- 每个信念训练种子使用 100 个新布局，交换阵营，分别进行 M–A、J–A、J–M 三组比较。
- 两个信念种子共 **1,200 个完整对局**；每组比较 400 局。固定策略只有一个训练种子，这不是策略种子的独立复验。
- 种子 20261004 的正式布局从 95000000 起；种子 20261005 从 96000000 起。同一信念种子的三组比较共用布局，两个种子使用不同布局。
- 排除信念数据、前轮正式/工程对局和本轮开发布局；保留排除来源及哈希。
- 两个信念种子分别报告完整布局配对 bootstrap 区间，另作探索性汇总；不能将同一布局的阵营交换当作独立样本。
- J–M 是机制比较的主要结果，M–A 与 J–A 为系统效果比较。三项结论一起展示，不能事后只选择最佳结果。
- 不完整局、失败或未配对记录不能计入胜率；采样/约束预算失败直接报错，没有基线回退。
