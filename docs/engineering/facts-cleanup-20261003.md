## 回归中发现并修复的问题

- 评测遇到 NaN/Inf 分布时可能选出非法动作。CPU H2H 和共享随机 / GPU 对战入口现在检查合法动作分布，无效输出立即报错。非法动作的正常 `-inf` 不报错；不回退为均匀策略。
- CPU 采样器的三分类价值正负号与 `[-1, 0, +1]` 训练目标、GPU 实现相反，已统一为 `P(win)-P(loss)`；step 和 bootstrap 共用转换。兼容 `(B,)`、`(B,1)` 标量输出，拒绝其它错误形状。
- GPU buffer 的 CPU 测试替身补齐全局维度字段。两组历史迁移测试允许显式指定外部起点文件；仅文件缺失时跳过，损坏权重或迁移错误仍失败。
