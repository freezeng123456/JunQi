## 工作方式

新任务先更新并核对 `origin/main`。功能分支可以用于隔离开发，但 PR 的目标
统一为 `main`。历史文档中的 master 仅表示当时的分支名称，不作为新任务基线。
服务器当前检出版本、训练检查点的输入通道与网络类型需单独核对；分支收敛
不会把旧模型权重自动迁移成新模型。
